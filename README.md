# Flores para Celeste

Experiencia romántica interactiva en tres fases: rosas rojas, girasoles y una carta con un mensaje íntimo para Celeste.

## Ejecutar localmente

```bash
pnpm install
pnpm dev
```

El texto de la carta se puede editar en `client/src/pages/Home.tsx`, dentro de `LETTER_LINES`.

La publicación se realiza automáticamente en GitHub Pages después de cada push a `main`.
